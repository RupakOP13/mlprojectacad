About SpamShield AI

End-to-end SMS spam detection using NLP and classical ML

🎯

Project Goal

Build a robust SMS Spam Detector that accurately classifies messages as spam or legitimate (ham) using Natural Language Processing and Machine Learning techniques.

📊

Dataset

Trained on the UCI SMS Spam Collection dataset containing 5,574 real SMS messages, labeled as ham (legitimate) or spam. Class imbalance handled during evaluation.

🔬

Approach

TF-IDF vectorization with n-grams (1,2) combined with four classical ML classifiers. Best model selected based on F1-Score to handle class imbalance.

🚀

Deployment

Flask web app with a real-time prediction API, interactive analytics dashboard, and feature transparency panel showing why a message was flagged.

🤖 ML Models Used

NB

Naive Bayes (Multinomial)

Classic probabilistic classifier that applies Bayes theorem with the naive assumption of independence. Extremely fast and effective for text classification. Uses word frequency features.

FastProbabilisticBaseline
LR

Logistic Regression

Linear model for binary classification using the logistic (sigmoid) function. Excellent regularization with L2 penalty. Provides probability estimates and highly interpretable coefficients.

InterpretableRegularizedEfficient
SVM

Support Vector Machine

Finds the optimal hyperplane maximizing margin between classes. Linear kernel with calibrated probabilities. Excellent performance on high-dimensional text feature spaces.

High-DimensionalMax-MarginRobust
RF

Random Forest

Ensemble of 200 decision trees using bagging and random feature selection. Highly resistant to overfitting. Provides feature importance scores for model interpretability.
